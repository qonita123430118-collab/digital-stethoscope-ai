# Pengembangan Stetoskop Digital Berbasis AI

## Deskripsi Proyek
Proyek ini merupakan bagian dari mata kuliah Perancangan Sistem Biomedis II, Program Studi Teknik Biomedis, Institut Teknologi Sumatera.

Penelitian bertujuan mengembangkan stetoskop digital berbasis ESP32 dan kecerdasan buatan untuk membantu skrining awal kelainan suara jantung melalui klasifikasi sinyal fonokardiogram (PCG) menjadi kategori normal dan abnormal.

## Tujuan Pengembangan
1. Mengembangkan sistem akuisisi suara jantung menggunakan sensor akustik dan ESP32.
2. Menerapkan pemrosesan sinyal digital untuk meningkatkan kualitas sinyal PCG.
3. Mengembangkan metode ekstraksi fitur MFCC dan klasifikasi menggunakan CNN.
4. Mengevaluasi kualitas sinyal, kinerja perangkat, dan hasil klasifikasi AI.
5. Mengembangkan antarmuka untuk visualisasi sinyal dan hasil analisis.

## Rencana Dokumentasi
- Hardware: Desain perangkat keras, skematik, dan komponen.
- Firmware: Pemrograman ESP32 dan sistem akuisisi.
- AI Model: Preprocessing, MFCC, pelatihan, dan evaluasi CNN.
- Web Dashboard: Antarmuka pengguna.
- Testing: Metode dan hasil pengujian.
- Docs: Dokumen perancangan dan pengembangan.

## Status Proyek
Proyek dalam tahap pengembangan. Implementasi, pengujian, dan validasi akan diperbarui berdasarkan progres aktual.

## Tim Pengembang
Kelompok 11 — Teknik Biomedis, Institut Teknologi Sumatera.

## Catatan
Repositori ini digunakan untuk dokumentasi akademik dan pengembangan prototipe, bukan sebagai bukti validasi klinis atau alat diagnosis medis yang telah tersertifikasi.
